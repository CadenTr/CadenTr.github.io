# CadenTrahan.com

Static GitHub Pages portfolio for Caden Trahan, organized around Surveying, Engineering, and Music.

## Local preview

Serve the repository root with any local static-file server, then open `index.html` through that server. The site has no package manager, framework, or build step. The North Carolina case study loads Three.js modules from jsDelivr; its QGIS poster image remains available if the interactive viewer cannot load.

## Site files

- `index.html` — Home, About, Résumé, Contact, and site-wide metadata
- `surveying.html`, `engineering.html`, `music.html` — dedicated discipline pages
- `nc-topo.html` — full QGIS and fabrication case study with an interactive model derived from the real project geometry
- `independence-park.html` — deed and boundary-history case study
- `styles.css` — responsive visual system
- `script.js` — accessible navigation, command search, hero topic switching, and progressive reveals
- `nc-topo-viewer.js` — Three.js contour-layer slider, orbit controls, and profile selection sync
- `assets/images/` — licensed stock images, Caden's headshot, and the North Carolina QGIS project render
- `assets/models/` — named contour-sheet model and its viewer manifest, derived from the North Carolina fabrication layers
- `assets/documents/` — résumé and academic Civil CAD plan PDFs
- `assets/audio/` — local playback renders of selected arrangements used on the music page
- `CNAME` — custom domain for `cadentrahan.com`
- `ASSET-CREDITS.md` — image sources and license record

Professional work is intentionally described at a general level. No client drawings, parcel-owner information, internal trackers, credential IDs, or proprietary deliverables are published.

The North Carolina QGIS project and Independence Park research are personal projects. The 3D model is a lightweight display derivative of the QGIS fabrication geometry; its vertical relief is exaggerated for screen legibility.

The Civil CAD sheet is academic work and is labeled preliminary, not for construction. Music previews retain the original composer credits shown on the source scores.

The signature styling reserves the `Bright Sunshine` family name and currently falls back to locally available script fonts. Add a properly licensed Bright Sunshine webfont kit before publishing the exact typeface.
